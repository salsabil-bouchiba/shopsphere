# ShopSphere — Frontend

React 19 + Vite SPA for the ShopSphere e-commerce app.

## Scripts

```bash
npm install
npm run dev        # http://localhost:5173
npm run build
npm run lint
npm run screenshots  # regenerates docs/screenshots (backend + frontend must be running)
```

## Environment

Copy values into `.env` (see root README):

```
VITE_API_URL=http://localhost:5000/api
VITE_STRIPE_PUBLISHABLE_KEY=
```
